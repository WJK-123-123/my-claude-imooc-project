# 财务管家 · 前端原型（Stitch 生成）

由 [Stitch](https://stitch.withgoogle.com) 生成的高保真 UI 原型，共 12 页，已按
《[财务管家-PRD-V1.0](../../001.产品PRD/财务管家-PRD-V1.0.md)》整理目录结构并完成页面间跳转接线。

## 怎么查看

**默认首页是 `pages/02_login.html`（登录页）**，两种方式任选：

```bash
cd 003.前端代码/frontend && python -m http.server 8080
# 浏览器访问 http://localhost:8080/pages/02_login.html（根路径无 index.html，会是目录列表）
```

或直接双击 `pages/02_login.html`。页面样式依赖 Tailwind CDN，**需联网**渲染。

## 30 秒上手

1. 打开 `pages/02_login.html`，落在登录页（注册已拆为独立页 `02_register.html`，两页底部链接互跳）；
2. 页面里的**真实按钮**已按 PRD 流程接线，直接点即可走通主流程：

```
02 登录 ⇄ 02 注册（没有账号？立即注册 / 已有账号？直接登录）
02 登录 → 05 记一笔 → 06 流水 → 07 年度统计
                              06 流水 → 09 账单详情（编辑/删除）
10 我的 → 11 退出与注销 → 回到 02 登录
辅助：02 登录 → 03 找回密码（三步）→ 回 02 登录
```

## 跳转说明

- **真实按钮接线**：登录/注册互跳、登录 → 场景引导、忘记密码 → 找回密码、场景选择 → 记一笔、
  流水 ↔ 统计、我的 → 退出注销等关键路径，已按 PRD 流程把页内按钮接上目标页面
  （覆盖 Stitch 原有的 `alert` 占位）。
- **顶栏头像圆钮**：03/05/06/07/08/11 六页右上角的人像圆钮已从静态图标改为按钮，
  点击跳转个人中心（`10_profile.html`），悬停微放大示意可点。
- **导出数据（07 页，演示）**：页面底端全宽「导出数据」按钮可将本页演示数据生成 CSV 下载
  （纯前端 Blob，带 BOM 防 Excel 乱码），文件名与内容月份跟随日期药丸联动。注意：导出在
  PRD V1 范围外（3.2 范围外清单），此处仅为原型交互演示，不代表进入 V1。
- 接线逻辑集中在 **`assets/proto-nav.js`** 一处，每页只在 `</body>` 前注入一个携带 `data-page` 的
  `<script>` 引用（搜索 `proto-nav` 标记可定位），不改动 Stitch 原稿的主体结构。

## 与 Stitch 导出原稿的差异

1. 每屏一目录的原稿（`_1 ~ _11`）整理为「编号_英文语义名」平铺文件，编号保留主流程顺序；
2. 登录屏两次生成稿（原 01/02）先合并为一张合版页，后又按 PRD F1「登录/注册/找回密码三页分立」
   **拆分为 `02_login.html`（登录）与 `02_register.html`（注册）两页**，底部互设跳转链接；
3. **无总览页、无根目录 index.html**：`pages/02_login.html` 即默认首页与唯一入口；
4. `code.html` → `NN_name.html`，`screen.png` → `NN_name.png`（03–11 有截图，02 两页为拆分所得、无原稿截图）；
5. `financial_steward/DESIGN.md` → `assets/DESIGN.md`；
6. 每页注入共享脚本引用（`assets/proto-nav.js`）：流程接线；
7. `06`/`07` 两页日期控件重做成同一套：原演示占位有缺陷（07 的 `changeMonth` 会误改顶栏标题——
   `querySelector` 命中「统计」而非日期药丸；06 的箭头则完全没接线），现为——顶栏恒显页面名、
   全页唯一日期药丸（`<`/`>` 按天步进，跨月跨年自动进位、闰年正确），点药丸弹出日历小框直选年月日
   （样式同 11 页弹窗）；
8. 新增两张管理页并从「我的」进入：`12_account_manage`（支付账户标记管理）与
   `13_category_manage`（支出/收入分类管理），均支持 emoji 选择与增删改查（2026-10-19 起
   改为仅内存演示：当页即时生效、刷新即还原初始数据，正式存取待接数据库；进页时顺手清除
   旧版残留的 localStorage 键）——系原型交互演示，账户非 PRD V1 的多账户余额体系；
9. `05` 记一笔页的分类九宫格与账户药丸改为动态渲染，优先读 localStorage
   （`fgj_demo_cats`/`fgj_demo_accounts`，键空则回退页内默认；`12`/`13` 改为仅内存演示后
   不再写入这两个键）；
   支出/收入为两套画面——樱花粉/薄荷绿双主题（Tab、金额卡、保存键联动换色）、各自分类
